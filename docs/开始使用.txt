社区管理 · 本地版

一、打开软件
打开“运行版”文件夹，双击“启动社区管理.cmd”。浏览器会自动打开。
运行期间保留程序窗口；结束时到程序窗口按 Ctrl+C。
初次使用无需安装 .NET、Node.js 或 Office。导出的 Word、Excel 文件可用 WPS 或 Office 打开。

二、第一次设置
1. 打开“设置”，填写单位名称、默认检查人，保存。
2. 在“网格”中添加本社区的网格。
3. 在“人员与检查类型”中添加工作人员、检查类型和检查项目。
   需要固定巡查时，给检查类型设置每周、每月或每季度及适用范围。

三、登记一个地方
打开“地图”→点“标点”或“画区域”→画好后“保存为新场所”。
填名称、网格、形态、地址等。多边形画好后可以拖动节点，吸附可开关。
已有场所：点地图标记→“修改位置”→调整→保存到该场所。
在场所档案的“经营和使用情况”中登记商店、仓库、出租房等，可同时选择多个用途。
一栋楼有多户时，先添加楼层、房间等单元，再给每个单元登记经营使用。
商店换人、退租时，将旧使用记录结束，再新增记录；不要直接把旧记录改成新商户。

四、登记检查
首页“登记检查”→选择场所→选择检查类型和检查对象→填写日期、检查人。
没有建档的地方选择“临时场所”，在地图上标点或圈区域。
无问题：选“未发现问题”，添加照片，保存。
有问题：选“发现问题”，逐项写清问题、要求、期限、责任单位并上传照片，保存。
没检查完：选“未完成检查”，写原因。它不会算作完成一次巡查。
没填完可点“存草稿”，下次从“草稿箱”继续。其他设备也能打开这份草稿。

五、跟踪整改
从首页待办或检查记录打开问题。
可以登记跟进记录、转交责任单位、延期、安排跟进人员。
整改后登记“反馈”；复查合格后完成，不合格可以退回继续整改。
每个问题单独办理，一次检查的多个问题可以有不同期限。
录错的记录使用“作废”，在设置的“作废记录与恢复”中可恢复，照片和历史保留。

六、安排和报表
首页“检查安排”：指定人员、检查类型、期限和场所，按记录自动显示进度。
首页“本期应检查”：查看设定周期内尚未完成的场所；未完成检查不会抵扣。
“工作统计”：按时间和网格统计。整改数据是这些检查所发现问题的当前状态。
“统计导出”：先查询，再导出 Word 或 Excel；可勾选最多200条，只导出勾选内容。
场所详情右上角“更多”可导出含经营记录和照片的档案 Word。
检查详情可以导出检查记录、整改通知和完成后的整改记录。

七、手机访问
电脑和手机连接同一局域网。电脑软件必须保持运行，电脑不要休眠。
在电脑首页右上角点“仅本机”，选择局域网监听并“应用”，复制显示的电脑局域网网址给手机浏览器打开。
有多个网卡时使用连接办公室路由器的地址，通常类似 http://192.168.x.x:5180。
手机和电脑使用同一套页面、同一份资料；手机可直接选相册或拍照上传。
不需要外网，但离开局域网后不能继续访问。没有另外的离线手机同步功能。
若 Windows 询问网络访问，允许办公室的专用网络。访客 Wi-Fi 的设备隔离可能阻止访问。
目前沿用 hbtool 的可信局域网模式，没有账号权限分级；拥有访问地址的人可以共同登记，请勿映射到公网。

八、地图和导入
已带入原 E:\Map 的吉林一号缓存，约31.8 MB，12—18级，只覆盖原有缓存范围。
离开缓存区域会提示暂无缓存，不会自动从互联网下载。
“地图→图层”可添加、开关、调整顺序/透明度、设置默认图层。
在运行软件的电脑上可“导入地图缓存”，选择 z/x/y 格式文件夹；原Map吉林一号选 TMS。
“设置→导入场所、网格”支持 Excel .xlsx 和 UTF-8 CSV，先预览和修正再导入。
原 E:\Map\GridData.xlsx 的部分名称含乱码，需在预览中修正。
地图保存坐标使用 WGS84。从高德或腾讯复制的坐标，使用“从其他地图粘贴坐标”并选择对应来源。

九、备份和换电脑
定期在“设置→备份”下载 ZIP，保存到另一块磁盘或 U盘。它包含资料、草稿、历史、照片。
地图缓存单独保存在 tiles 文件夹，换电脑时也要复制。
每日自动快照只包含数据库，不包含照片，不能代替完整备份。
最省事的搬迁方式：先正常关闭软件，再复制整个“运行版”文件夹到新电脑。
不要只拿走 CommunityGIS.exe；wwwroot、data、photos、tiles 等需要一起保留。
恢复 ZIP 会覆盖当前资料，界面先预览并确认，覆盖前会保留旧资料。

十、文件位置
CommunityGIS.exe：程序
wwwroot：网页及本地图标、地图引擎、图片压缩组件
data：数据库（首次启动自动生成）
photos：上传后的照片
tiles：本地地图缓存
backup：数据库快照和恢复前保留资料
temp：导出、恢复等临时文件

开发源码位于运行版上一级目录的 server 和 web 中；原 Map 项目没有改动。
