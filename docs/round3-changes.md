# 本轮功能改动

- 整治通过 `pointId` 或 `newPoint` 二选一关联点位；临时点位与整治同事务保存，复用排查的点位校验。点位删除保护、临时点位最后记录清理同时考虑排查与整治。
- 点位详情显示历史整治，并提供预选当前点位的“新增整治”。照片仅在编辑窗口增删，详情保留预览。
- 点位管理的导出台账可选择一个或多个点位。三种台账复用现有导出路径，只增加重复 `pointId` 参数；日期、社区、整治类型均按弹窗选择，统计口径不变。
- 整改期限标签同行显示原有默认期限提示，不改变日期规则。
- 所有坐标编辑字段提供“选取”链接。原提供的网址存在重复字符，采用高德可用入口 `https://ditu.gaode.com/ssr/coordinate-picker`。仅用户点击时新窗口访问，页面不加载外部地图资源。
- 排查人、默认排查人、联系人、责任单位、组织单位、参加单位及人员以标签编辑/展示。逗号、句号（中英文）、空格、换行作为输入分隔符；后端字段仍是字符串，提交以单空格连接，未完成输入同时写入草稿。名称不去重、不拆电话、街道全称和社区抬头。
- 模板变量按钮在光标/选择区插入，鼠标点击不使文本框失焦；不改模板正文或重复变量校验。

当前数据库 schema 为 3，整治草稿为新格式。本轮不提供旧版数据库/草稿迁移；旧数据库无损拒绝，不自动清空文件。开发测试使用新目录。现行备份一致性、恢复中断保护、照片归属校验、批量办理事务和 Warning 日志下限保留。

测试新增：点位整治关联、双记录生命周期、三类台账点位过滤、标签分隔/中文输入/未提交草稿、只读照片区、选点入口、模板光标插入。完整回归和平台发布结果以本轮 GitHub Actions 原始附件为准，不沿用上一轮数字。
