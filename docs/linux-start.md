# 街道生态环保工具 · Linux ARM64

1. 将整个 `hbtool` 文件夹解压到可写目录。
2. 双击“街道生态环保”图标（`启动应用.desktop`）。如果首次提示“允许启动”或“信任”，请选择允许。
3. 程序无需安装 .NET。终端会保持打开，启动后自动打开浏览器；也可以访问终端显示的网址。

退出时，在终端按 **Ctrl+C** 停止程序，再按回车关闭终端。启动图标和 `start-linux.sh` 需与程序保存在同一文件夹。

默认只允许本机访问。要让手机访问，在首页的“访问设置”选择需要的网卡，然后用手机打开显示的局域网地址。请在可信网络中使用。
