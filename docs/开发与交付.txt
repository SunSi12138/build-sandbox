CommunityGIS 开发与交付

源码分支：community-gis。技术栈：.NET 10 Native AOT + SQLite；Nuxt 4 / Nuxt UI；OpenLayers 10。
目标平台：Windows x64。前后端一起发布，运行时不需要安装 .NET 或 Node.js。

构建
.NET SDK 10.0.302、Windows C++ 构建工具、Node.js、pnpm。
web：pnpm install --frozen-lockfile；pnpm typecheck；pnpm generate。
后端：dotnet publish server/StreetEcoTool.csproj -c Release -r win-x64 -p:PublishAot=true -o release。
scripts/build-community.ps1 可构建并装配“运行版”；更新前先关闭该运行目录中的程序。
运行版包含 CommunityGIS.exe、wwwroot、地图缓存及本地地图配置。配置中的密钥不提交 Git。

当前数据契约
数据库仅接受 schema 6，并检查最终结构。新库在一个事务内创建完整结构及默认分类。
没有旧版本升级、启动补字段、修订旧模板或重写用户默认值的分支。
其他数据版本会拒绝打开或恢复，不会转换或删除原数据；需要使用新目录启动。
Excel / CSV 网格导入、备份恢复、历史记录快照属于当前业务功能，保留。
坐标统一保存 WGS84；文件导入中的来源坐标换算保留。

本机开发
web 的 pnpm dev 代理 localhost:5180。Nuxt 使用 hash 路由，例如 /#/map。
服务端开发数据独立于运行版；浏览器检查不要使用真实业务库作测试资料。
