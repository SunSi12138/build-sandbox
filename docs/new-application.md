# 使用说明

## 功能入口

首页、点位、排查、事项、活动、设置。整改问题在排查详情中办理。

### 事项办理

用于群众反映、热线转办、上级交办、日常发现和其他事项。收到事项时即可登记标题、来源、日期和内容，点位、期限、经办人、编号及联系方式按需补充。

事项状态为待办理、办理中、已办结。办理过程可追加记录、回复和移交；办结填写已解决、未发现相关问题、已移交或撤销/重复等结论。选择“已解决”前，关联问题须已闭环。重新办理保留原有过程。

一个事项可关联多次排查、多个问题和多次活动。一条业务记录也可关联多个事项。从事项详情可新建排查/活动，也可关联已经存在的排查、问题或活动。问题反馈及复查不会自动替代事项办结。

### 点位档案与附件

点位包含基本资料、现场照片、标签、历史排查、相关事项和活动。支持常态点位及随现场记录创建的临时点位。

点位附件保存原文件，单个不超过25MiB，支持PDF、Word、Excel、JPEG、PNG、TXT和ZIP。PDF和图片可预览；其他文件下载查看。附件可以改名和加备注，改名保留扩展名。同名文件分别保存，不覆盖旧文件。

存在业务记录或附件的点位不能直接删除，可停用；移除附件需要明确确认。删除临时点位最后一条现场记录时，只会清理没有其他业务记录、事项或附件引用的临时点位。

### 地图位置

点位和排查的列表与地图共用筛选条件。点位支持地图选点、画区域；排查保存当时的位置快照，不随点位后续移动。底图优先使用本地tiles缓存，新范围首次加载需要配置地图服务并联网。

### 排查与整改

排查来源为日常巡查、事项核查或其他。事项核查选择相关事项后，记录实际排查结果；没有发现问题也可保存。

单项问题独立选择问题类型和相关事项。排查只关联一个事项时，新问题默认关联该事项，可调整；排查关联多个事项时逐项选择，避免错误归属。既有问题可在详情中补充事项关联。

整改流程保留待整改、已反馈、复查闭环以及退回继续整改；问题照片、历史反馈和复查记录按实际办理保存。

### 活动与整治

活动统一管理会议、宣传、学习、培训、志愿服务及整治。普通活动可不关联点位；内置整治类型必须关联常态或临时点位，并填写整治类别。

整治模板提供车辆数、垃圾吨数、清理面积，以及整治前/中/后照片。公共字段和活动列表共用；已保存记录不能跨普通/整治模板转换。内置整治类型可改显示名称，不能删除或变为普通模板。

活动可关联事项和已有整改问题。关联表示工作依据，问题闭环仍通过反馈与复查完成。

普通活动和整治分别导出相应记录单。通用活动台账可包含两类活动；整治专用台账保留数量汇总和阶段照片。

### 标签

设置中统一新增、改名、停用标签。事项、点位、排查和活动各自保存标签，点位标签不会自动传播到以后每次记录。

已停用标签保留在历史记录中，不再添加到其他记录；已使用标签不能直接删除。列表选择多个标签时，结果须同时具有这些标签。点击标签可分组查看相关事项、点位、排查和活动。

### 筛选与导出

列表导出默认沿用当前条件，导出所有匹配记录，不限当前分页。范围摘要和预计数量会显示在弹窗中，也可选择自定义范围。标签、事项、问题类型等条件参与实际导出。

点位管理可选择多个点位导出排查、整改或整治台账。

## 数据目录

当前数据库结构版本为5，新部署使用全新数据目录。

数据目录：

```text
hbtool/
  data/app.db
  photos/yyyyMM/
  attachments/yyyyMM/
  backup/
  temp/
  wwwroot/
```

## 备份和恢复

“下载完整备份”包含数据库、登记的原图/缩略图和点位附件。恢复前预览点位、排查、问题、活动、整治子集、事项、附件和标签数量。附件按大小、格式和SHA-256核对；缺失、额外、损坏或越界文件会拒绝恢复。

确认恢复会覆盖当前数据，覆盖前保留数据库、照片和附件。恢复中断时依据恢复日志回滚；三类数据保持同一版本。

每天的自动数据库快照仍不包含照片与附件，保留最近14份。搬迁时正常停机并复制完整程序目录，或使用完整ZIP备份。
