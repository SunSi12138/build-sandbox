# 文件助手

局域网匿名文件接收，单可执行文件，内置 HTML/CSS/JS。无外网请求、云服务、账号或数据库。默认保存到程序同目录 Files，可通过 --dir 指定。

Linux 麒麟 V10 ARM64：解压构建产物中的 tar.gz（保留执行权限），双击 文件助手.desktop（桌面环境可能要求“信任并启动”），或运行 ./FileAssistant。Windows：双击 FileAssistant.exe。命令行显示可扫描二维码和地址。若自动选择网卡不正确，使用 --ip 指定本机 IPv4；--port 默认 8899。允许可信局域网访问该 TCP 端口，不做公网映射。

选文件后自动上传，2 MiB 分块，当前页面保持打开期间自动重试/手动续传。关闭页面、接收端重启后重新选择文件从头上传；启动清理残留暂存文件。相同内容 SHA-256 去重（启动时索引已有文件和运行期间本程序写入的文件）；同名异内容自动编号。保存目录只存一份已完成文件，另有隐藏暂存目录用于处理中数据。运行时外部新增文件需重启索引。不要把保存目录共享给不可信本机用户，不建议使用公共 Wi-Fi。HTTP 明文传输；客户端仅能上传，不能列出、下载、删除已保存文件。

微信能否离线扫码打开局域网 HTTP 地址、能否选微信聊天中的文件取决于微信客户端及 OS 文件选择器，H5 不调用小程序专用接口。微信无法打开时用系统相机扫码或手机浏览器输入地址。局域网链路本身中断需恢复连接。

构建：沿用 hbtool 的 net10.0、AOT 严格警告、Ubuntu 20.04 ARM64、GLIBC <=2.31 校验。GitHub Actions 分支 file-assistant 的独立 workflow 发布 Windows x64 和 Linux ARM64 产物，并在 native binary 上执行 API smoke。
